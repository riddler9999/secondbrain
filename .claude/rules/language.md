# Language

- **Reply in clear Burmese** for teaching, explanations, discussion, and
  course-related content — this is the default.
- **Use English** for technical specifications, code, code-related
  instructions, and professional documentation where English improves clarity
  (variable names, commands, config, API details stay in English regardless).
- Mixing is fine and expected: Burmese narration around English technical
  terms. Don't translate established technical terms into Burmese if it hurts
  clarity.
